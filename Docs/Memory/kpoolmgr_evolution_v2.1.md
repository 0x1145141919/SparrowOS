1. HCB_v2 → HCB_v2.1 回滚与迭代                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                            
### 动机                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                            
HCB_v3 (BCB_fnd_DeepFirst buddy tree) 作为通用堆分配器利用率过低：2^N×32B 固定粒度导致平均内部碎片 20~50%。回归 HCB_v2 的 flat bitmap + next-fit cursor 方案，调参迭代为 v2.1。                                                                             
                                                                                                                                                                                                                                                            
### HCB_v2.1 核心变化                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                            
┌───────────────┬───────────────────┬────────────────────────────┐                                                                                                                                                                                          
│ 参数          │ HCB_v2            │ HCB_v2.1                   │                                                                                                                                                                                          
├───────────────┼───────────────────┼────────────────────────────┤                                                                                                                                                                                          
│ bytes_per_bit │ 16B               │ 8B                         │                                                                                                                                                                                          
├───────────────┼───────────────────┼────────────────────────────┤                                                                                                                                                                                          
│ metadata size │ 16B (alignas 16)  │ 8B (alignas 8)             │                                                                                                                                                                                          
├───────────────┼───────────────────┼────────────────────────────┤                                                                                                                                                                                          
│ 最小分配单位  │ 32B (16+16)       │ 16B (8+8)                  │                                                                                                                                                                                          
├───────────────┼───────────────────┼────────────────────────────┤                                                                                                                                                                                          
│ 校验          │ sentinel bit only │ sentinel bit + 0xFF canary │                                                                                                                                                                                          
└───────────────┴───────────────────┴────────────────────────────┘                                                                                                                                                                                          
                                                                                                                                                                                                                                                            
### data_meta 结构                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                            
```cpp                                                                                                                                                                                                                                                      
  struct alignas(8) data_meta {                                                                                                                                                                                                                             
      uint32_t data_size;       // 4B, 打包粒度以下无需记录                                                                                                                                                                                                 
      uint8_t  alloc_flags;     // 1B                                                                                                                                                                                                                       
      uint8_t  magic;           // 1B, debug 保留                                                                                                                                                                                                           
      uint16_t reserved;        // 2B, 可扩展 (crc/tail_magic)                                                                                                                                                                                              
  };                                                                                                                                                                                                                                                        
```                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                            
### 校验方案                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                            
Release 模式：                                                                                                                                                                                                                                              
- 默认路径：meta(8B) + ceil(user, 8)B                                                                                                                                                                                                                       
- 不足 8B 的 padding 填充 0xFF                                                                                                                                                                                                                              
- free() 时检查 padding 0xFF → 检测小范围越界 (1~7B)                                                                                                                                                                                                        
- double_free 检测链：magic 校验 → 若经过第一次 free 清零 → magic=0 → panic                                                                                                                                                                                 
- 多余备份：ksetmem_8(meta, 0, 8) 全零 → data_size=0 在任何绕过 magic 检查的路径上同样 panic                                                                                                                                                                
                                                                                                                                                                                                                                                            
Debug 模式 (KPOOL_VALIDATE)：                                                                                                                                                                                                                               
- 每 allocation 末尾追加独立 8B tail_magic                                                                                                                                                                                                                  
- tail_magic = imul(ptr, GOLDEN) ^ data_size                                                                                                                                                                                                                
- free() 时校验：tail_magic 匹配 → 越界检测                                                                                                                                                                                                                 
- per-HCB 随机种子 (salt)，防止跨堆构造碰撞                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                            
### 锁与统计                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                            
- HCB_v2 的 bitmap_rwlock + used_bit_count_lock 维持不变                                                                                                                                                                                                    
- 新增 per-allocation hash 统计（size bucket + peak 监控）                                                                                                                                                                                                  
- scan_cache 全部保留（hint_u64_idx, last_success_idx, largest_free_hint）                                                                                                                                                                                  
                                                                                                                                                                                                                                                            
### 实测                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                            
待实体机 22 核环境跑 memalloc_stress 后补充数据。

2. 内核 MMU 改进计划：层级导出机制                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                            
### 问题陈述                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                            
当前架构中，所有页表操作（内核空间 4KB/2MB/1GB 映射、取消映射）均经过 out_surfaces.cpp 的全局大锁 kspace_pagetable_modify_lock，导致：                                                                                                                      
                                                                                                                                                                                                                                                            
- 不同内核子系统的页表操作互相阻塞                                                                                                                                                                                                                          
- 多核扩展性差（22 核环境下锁争用显著）                                                                                                                                                                                                                     
- 进程地址空间（未来用户态）的页表操作无法复用此路径                                                                                                                                                                                                        
                                                                                                                                                                                                                                                            
### 总则                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                            
- per-resource 独立管理取代全局串行化                                                                                                                                                                                                                       
- 每个子系统有明确的自有页表域（PD entry 范围）                                                                                                                                                                                                             
- 自管域内的页表修改不经过全局大锁                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                            
### 导出层级：PD Level（Page Directory，2MB 粒度）                                                                                                                                                                                                          
                                                                                                                                                                                                                                                            
导出内容：                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                            
```cpp                                                                                                                                                                                                                                                      
  // 给 kpoolmemmgr 的专用接口（3条，无全局锁）                                                                                                                                                                                                             
  namespace KspacMapMgr {                                                                                                                                                                                                                                   
      KURD_t install_hcb_pde(vaddr_t vbase, phyaddr_t pbase);    // 写一条2MB PDE                                                                                                                                                                           
      KURD_t uninstall_hcb_pde(vaddr_t vbase);                   // 清一条PDE                                                                                                                                                                               
      bool   check_hcb_pde(vaddr_t vbase);                       // 检查PDE是否存在                                                                                                                                                                         
  }                                                                                                                                                                                                                                                         
```                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                            
使用方： kpoolmemmgr_t::HCB_v2.1                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                            
理由：                                                                                                                                                                                                                                                      
- HCB 数据区固定 2MB，天然 2MB 对齐 + 物理连续                                                                                                                                                                                                              
- 一个 PDE 覆盖整个 HCB，无需拆成 512 个 PTE                                                                                                                                                                                                                
- HCB 的 online/offline（堆初始化/销毁）频率极低，不在 hot path                                                                                                                                                                                             
- per-HCB 的页表操作不影响通用 VM 映射                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                            
扩展路径：                                                                                                                                                                                                                                                  
- 当前：HCB 专用                                                                                                                                                                                                                                            
- 后续：每个内核子系统的固定大小区域（内核栈、per-CPU 数据块、设备 MMIO 区域）                                                                                                                                                                              
- 再后续：用户态进程地址空间（per-process PDE 管理，切换 CR3）                                                                                                                                                                                              
                                                                                                                                                                                                                                                            
### 锁模型过渡                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                            
```                                                                                                                                                                                                                                                         
  当前:                                                                                                                                                                                                                                                     
    kspace_pagetable_modify_lock (global) → out_surfaces → KspacMapMgr                                                                                                                                                                                      
                                                                                                                                                                                                                                                            
  过渡:                                                                                                                                                                                                                                                     
    kspace_pagetable_modify_lock (global) → out_surfaces (通用接口)                                                                                                                                                                                         
    (无锁 / per-HCB lock)                 → KspacMapMgr::install/uninstall_hcb_pde (专用接口)                                                                                                                                                               
                                                                                                                                                                                                                                                            
  未来:                                                                                                                                                                                                                                                     
    per-address-space lock → process page table manager                                                                                                                                                                                                     
    per-kernel-subdomain lock → kernel page table manager                                                                                                                                                                                                   
    (没有全局锁)                                                                                                                                                                                                                                            
```                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                            
### 回收与内存压力联动                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                            
HCB_v2.1 的 PD 独立管理使得回收闲置 HCB 变得干净：                                                                                                                                                                                                          
                                                                                                                                                                                                                                                            
```                                                                                                                                                                                                                                                         
  内存压力回调:                                                                                                                                                                                                                                             
    for each HCB in HCB_ARRAY:                                                                                                                                                                                                                              
      if HCB is idle (used_bytes == 0):                                                                                                                                                                                                                     
        KspacMapMgr::uninstall_hcb_pde(hcb->vbase)   // 清 PDE，不需要锁                                                                                                                                                                                    
        FreePagesAllocator::free(hcb->pbase, 2MB)                                                                                                                                                                                                           
        hcb->valid = false                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                            
  重新激活:                                                                                                                                                                                                                                                 
    if HCB 需要被激活:                                                                                                                                                                                                                                      
      FreePagesAllocator::alloc(2MB, 2MB align)                                                                                                                                                                                                             
      KspacMapMgr::install_hcb_pde(vbase, pbase)                                                                                                                                                                                                            
      hcb->valid = true                                                                                                                                                                                                                                     
```                                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                            
此流程完全避开 out_surfaces 全局锁，可在中断上下文（内存压力回调）执行。                                                                                                                                                                                    
                                                                                                                                                                                                                                                            
### 路线图                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                            
1. Phase 1: 回滚至 HCB_v2 → 调参为 v2.1 (8B per bit + 0xFF canary)                                                                                                                                                                                          
2. Phase 2: 实现 install/uninstall_hcb_pde，kpoolmemmgr 切换为新接口                                                                                                                                                                                        
3. Phase 3: 内存压力回收回调接入 HCB_ARRAY                                                                                                                                                                                                                  
4. Phase 4: 抽象出 per-resource page table manager 框架，供用户态复用                                                                                                                                                                                       
5. Phase 5: 移除外层 out_surfaces 全局锁（改为 per-resource）
