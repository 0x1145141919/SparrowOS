## 0. 不变量（所有测试最终要证的目标）

- **INV-A 双调度**：任一 task 任一时刻至多登记在一个核的 `g_cpu_running[]` 上。
- **INV-B 登记一致性**：`g_cpu_running[c]==t` ⟺ t 正占用核 c 的栈（允许 F4 单步瞬态）。
- **INV-C 回收安全**：`release_kthread` 释放栈前，t 不在任何核登记中（无栈 UAF/二次分配）。
- **INV-D 唤醒不丢不重**：`wake_pending` 的「置位↔补投」一一对应，任务最终被唤醒且仅一次入队。
- **INV-E 门不泄漏**：`g_cpu_in_sched[c]` 置位必达清位。
- **INV-F 状态合法**：状态转移只走合法边（`task_state_machine.mmd`）。

## 15. 执行配方（复用现有工具）

```bash
cd /home/PS/PS_git/OS_pj_uefi/kernel

# 带测试分支构建（if_real_init=false → 测试档）
cmake -DKTHREAD_TEST_SCENARIO=ON . && make kernel.elf initramfs

# 冻结取证（#TB# 测试截停 / #WF# 异常冻结；需 ioport80 补丁 QEMU）
QEMU_BIN=/home/PS/PS_git/qemu/build/qemu-system-x86_64 \
  Tools/tcg-trace/tcg-trace.sh --tag sched --timeout 150 --stop-on 'PANIC|#TB#' \
  --dump-vmcore --mkcore

# 截停后栈检查（INV-A 等）+ 测试环
Tools/wraith/stackcheck.sh <tag>.core kernel.elf
python3 Tools/tcg-trace/ring-dump.py <tag>.core --kernel kernel.elf --symbol wraith_test_ring

# 还原默认构建
cmake -DKTHREAD_TEST_SCENARIO=OFF . && make kernel.elf initramfs
```

> 连跑带负载：前置 `for k in 1 2 3 4; do yes >/dev/null & done`，跑完 kill。
> `#TB#planned` = 干净跑到计划截停；`#TB#stack-canary-corrupt`/`#WF#`/PANIC/超时 = 命中异常。
