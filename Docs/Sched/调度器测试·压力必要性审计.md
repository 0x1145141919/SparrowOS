# 调度器测试 · 压力必要性审计（先审计，再开工）

> **动机**：上一版落地设计把所有组都套上「accel × stress(0/5/10/16/22) × ≥20」的核武器矩阵——
> 过重。**外部压力（宿主 `yes` 过订阅 + TCG 慢时序）是当初为逼出 WRAITH「多调度幽灵」才上的重武器**，
> 只对**失效依赖时序扰动的竞态类**用例才有边际价值；**功能基本可用性**用例不需要它。
> **配套**：`Docs/Sched/调度器待测清单.md` · `Docs/Sched/调度器压测落地设计.md`（施工图）。
> **审计口径**：逐 S-ID 判定是否需要「环境压力测试」，并给出**建议条件集**。

---

## 0. 三分类口径

| 类 | 含义 | 需要外部压力？ | 建议条件集 |
|---|---|---|---|
| **F** 功能核 | 确定性 / 单发 / 可注入；失效**不依赖**时序扰动，靠断言即可判 | **否** | `kvm+tcg` × 小 rep（5~10），**stress 档不用** |
| **C** 并发核 | 需要 **guest 内多核并发**才成立，但窗口较宽或可确定性注入 | **半**（弱扰动够） | `kvm+tcg` × stress 取 **{0,22}** 两点 × 适中 rep（10~20） |
| **S** 竞态核 | 失效**依赖强时序扰动**（先发布后切离 / 跨核偷取 / 中断嵌套 / 栈复用窗口）——WRAITH 同类 | **是（核武器）** | `kvm+tcg` × stress **{0,5,10,16,22}** × **≥20 rep** |

> 判据自问：**把外部压力全部关掉、宿主空闲、单核跑，这条用例会不会恒绿？**
> 会 → F；不会但能靠 guest 内多核+注入稳定打出来 → C；不会且必须外部扰动才出 → S。

## 1. 逐条审计（S-ID）

### 1 任务状态机

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-01 合法转移 | **F** | 否 | 纯状态真值表，单线程驱动即可 |
| S-02 非法转移拒绝 | **F** | 否 | 同上 |
| S-03 resurrect 语义 | **F** | 否 | 单对象语义，无并发 |
| S-04 GS↔state 一致 | **C** | 弱 | 运行态不变量；F4 允许单步瞬态 → 需长跑/探针，但窗口可自证 |

### 2 队列（ready/sleep）

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-10 入队/pop/重复拒绝 | **F**(核)+**C**(并发) | 弱 | 顺序正确=F；多线程重复拒绝=C |
| S-11 sleep 到点唤醒 | **F** | 否 | 单线程计时角色即可判对错 |
| S-12 时间边界（==/<） | **F** | 否 | 伪造 stamp 确定性打点 |
| S-13 sleep×bq 超时两路唤醒同任务 | **S** | **是** | 双路径竞争窗口，需强扰动 |

### 3 bq 系统

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-20 阻塞分支 | **F** | 否 | 单 waiter 阻塞即判 |
| S-21 未阻塞分支 | **F** | 否 | 先改 token 再调，确定性 |
| S-22 正常唤醒 pop_all+flush | **F** | 否 | 单 waiter 唤醒即判 |
| S-23 pop_all 入口复位（clamp 复用） | **F** | 否 | 同一 clamp 跨轮复用，确定性 |
| S-24 pop_timeouts >64 批量边界 | **F** | 否 | 灌 >64 orphan，确定性 |
| S-25 入口复位+提前停 | **F** | 否 | 伪造 stamp，确定性 |
| S-26 bq 状态机 enable/disable | **F** | 否 | 单对象状态真值表 |
| S-27 alloc/free 生命周期 | **F**(核)+**C**(container 读写锁并发) | 弱 | 生命周期+id 唯一=F；并发读写=C |
| S-28 flush 的 F4 分支（仍登记别核→pending） | **S** | **是** | 需精准命中「已发布未切离」窗口 |
| S-29 flush 的 MS-7/8（非 blocked 跳过/不重复） | **F** | 否 | 唤醒后再 flush，确定性 |
| S-30 多 waiter 多队列跨核归属 | **C** | 弱 | 需 guest 多核，但无强时序依赖 |

### 4 唤醒 / handoff（F4）

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-40 wakeup 对 blocked（已切离）→set_ready | **F** | 否 | 常规唤醒，单发即判 |
| S-41 wakeup 对「仍登记别核」→仅置 pending | **S** | **是** | 精准窗口，WRAITH 主嫌 |
| S-42 交接点补投 pending | **S** | **是** | 同上 |
| S-43 try_take 拒认领「仍登记别核」 | **S** | **是** | 跨核偷取压力下命中 |
| S-44 pending 置位↔补投 不丢不重 | **S** | **是** | 对账需足够事件量+扰动 |
| S-45 wakeup 幂等（ALREADY_RUNNING） | **F** | 否 | 连唤两次，确定性 |
| S-46 wakeup 拒 on_blockers_queue_bit | **F** | 否 | 直接注入该态 |

### 5 调度门 / 重入（F3）

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-50 resched 遇门→不嵌套 | **C** | 弱 | 可确定性注入（门置位时调 resched）；IRQ 下更真但非必须 |
| S-51 resched 返回分支调用方处理 | **C** | 弱 | 注入触发返回分支 |
| S-52 门置位必达清位（无泄漏） | **S** | **是** | 长时间压力+对账才靠谱 |

### 6 退出与回收（F5）

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-60 release 时仍登记别核→有界自旋不 vfree | **S** | **是** | 竞争下强制回收，窗口依赖扰动 |
| S-61 自旋耗尽→TASK_STILL_ON_CPU | **S** | **是** | 需卡死/强竞争 |
| S-62 窗口内栈不被二次分配 | **S** | **是** | 栈复用别名，需竞争+再派生同尺寸 |
| S-63 zombie_observe 三态 | **F** | 否 | 单发判定 |
| S-64 task_pool rb_tree 并发 | **C** | 弱 | 多线程撕裂，无强时序依赖 |

### 7 锁内快照 / 撕裂（F2）

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-70 sched 锁内快照不撕裂 | **S** | **是** | 高频 save/sched 交错，窗口极窄 |
| S-71 atomic_load_from iret 帧完整性 | **S** | **是** | 同上，野 RIP/RSP |

### 8 抢占 / resched / IPI

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-80 抢占路径（IPI/时间片→resched） | **S** | **是** | 需开抢占 + 混合负载 + IRQ 压力 |
| S-81 IPI 空槽防御 | **F** | 否 | 故障注入，确定性打 |
| S-82 中断上下文整段调度（设备 IRQ→resched） | **S** | **是** | 设备 IRQ 压力，WRAITH 拉长窗口的元凶之一 |

### 9 多核 / 并行度 / 观测

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-90 并行度回归 | **M**(测量) | 需多核负载（非核武器） | 修复前/后对照，量吞吐/切换/分布 |
| S-91 长批 ≥100 组 0 异常 | **S** | **是** | 本质就是压力矩阵的聚合判据 |
| S-92 观测效应 A/B | **S** | **是** | 金丝雀/探针开关须在压力下对照 |

### 10 时间 / 超时

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-100 sleep 唤醒精度+抖动 | **F**/M | 否 | 计时测量，低扰动更准 |
| S-101 heart_beat_alarm×调度交互 | **C** | 弱 | 需负载才压出交互，但非窄窗竞态 |

### 11 DTS

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-110 dts 记录+时间片+饥饿保护 | **F**(记录)+**C**(饥饿) | 弱 | 记录=F；饥饿保护需负载。**注：`dts_gantt_*` 当前未实现** |

### 12 端到端触发面

| ID | 类 | 外部压力 | 理由 |
|---|---|---|---|
| S-120 NVMe 并行初始化（原 WRAITH 触发面） | **S** | **是** | 就是当年出鬼的现场 |
| S-121 高核数 SMP≥8 显形率 | **S** | **是** | 核越多偷取/窗口越多 |

## 2. 按组归纳：谁配核武器

| 组 | 构成 | 定级 | 外部压力 |
|---|---|---|---|
| **G-A** STATE | S-01~03 全 F，S-04 C | **功能组** | 否（kvm+tcg × 小 rep） |
| **G-B1** BQ-FUNC | S-20~26,27(alloc),29,11,12 全 F | **功能组** | 否 |
| **G-B2** BQ-RACE | S-13,27(并发),30 | **竞态尾** | 是（并入 G-C 配方或单列小矩阵） |
| **G-C** HANDOFF | S-28,40~46（S-41..44 为 S） | **竞态核（核心）** | **是** |
| **G-D** RELEASE | S-60,61,62（S）+64（C） | **竞态核** | **是** |
| **G-E** PREEMPT | S-80,82,52（S）+50,51,100,101（C）+81（F） | **竞态核（混合）** | **是** |
| **G-F** TEAR | S-70,71（S） | **竞态核** | **是** |
| **G-G** DTS | S-110（F+C） | **功能组**（需先实现 gantt） | 否/弱 |
| **G-H** E2E | S-90(M)+S-120,121(S) | **竞态核+测量** | **是** |

**结论**：
- **需核武器的（S 类承载组）**：**G-C、G-D、G-E、G-F、G-H**，外加 **G-B2** 小尾。
- **不需要核武器的（功能组）**：**G-A、G-B1、G-G**。
- **C 类散点**（S-04/10/27/30/50/51/64/101）不单独立组，挂进所属组的**"弱扰动"轮**（stress {0,22}）。

## 3. 对矩阵的修订（成本重估）

| 层 | 组 | 条件集 | boot 数 |
|---|---|---|---|
| 功能轮 | G-A, G-B1, G-G | `2 accel × rep10`（无 stress） | 3×2×10 = **60** |
| 弱扰动轮 | C 类散点（挂各组） | `2 accel × {0,22} × rep10` | ≈ **80** |
| **核武器轮** | G-C, G-D, G-E, G-F, G-H, G-B2 | `2 accel × {0,5,10,16,22} × rep20` | ~6×10×20 = **1200** |
| 聚合 | S-91 长批 / S-92 A/B | 复算核武器轮结果 | 0（复用） |

- **原全集 ~1600 → 修订 ~1340**，且**核武器只压在 ~6 个组**上；功能可用性用**廉价功能轮**拿证据即可。
- 周末档：**T0 发烟(功能轮全绿)** 放周五晚 → **T2/T3 核武器轮** 占周末全天 → **T4 聚合 + 通稿**。

## 4. 一句话

**功能核（G-A / G-B1 / G-G）：关掉全部外部压力、单发断言跑绿即可，不进核武器矩阵。**
**竞态核（G-C / G-D / G-E / G-F / G-H，及 G-B2 尾）：这才需要 `kvm/tcg × 0/5/10/16/22 × ≥20` 的核武器。**
审计表见 §1。**本口径已落地** `调度器压测落地设计.md`（§2 口径 / §3 分组定级 / §4 条件集 / §7 成本）。
